# Fabric Capacity Monitoring Runbook

## Trigger

Investigate when workspace/capacity utilization exceeds the agreed operational threshold. The resume describes flagging usage above **75%**.

## Procedure

1. Identify the affected workspace/capacity.
2. Check recent deployment and pipeline activity.
3. Identify long-running or high-consumption operations.
4. Coordinate with Data Engineers/Developers before remediation.
5. Capture evidence in the incident record.
6. Recheck capacity after mitigation.

## Evidence

Record timestamps, workspace/capacity, operation IDs where available, impact, action taken and verification result.
