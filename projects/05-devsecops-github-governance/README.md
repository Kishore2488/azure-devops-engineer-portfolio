# 05 — DevSecOps GitHub Governance

A repository governance project demonstrating security controls that can be applied before code reaches production.

## Demonstrates
- Minimal GitHub Actions permissions
- Secret-pattern detection
- Dependency and code scanning concepts
- CODEOWNERS
- Branch protection recommendations
- Secure workflow design
- No credentials committed to source control

## Security gates

1. YAML validation
2. Secret-pattern check
3. Dependency review on pull requests
4. CODEOWNERS review
5. Least-privilege workflow permissions

This project is designed to run without cloud credentials.
