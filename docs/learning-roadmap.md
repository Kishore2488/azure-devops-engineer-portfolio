# Skill Elevation Roadmap

## Phase 1 — Core platform

- Azure DevOps Repos/Pipelines/Boards/Artifacts
- GitHub Actions reusable workflows
- YAML multi-stage pipelines
- Git branching and release management

## Phase 2 — Automation

- Ansible roles and collections
- Idempotency and inventory design
- Bicep modules and parameterization
- Automated validation

## Phase 3 — Kubernetes / AKS

- Deployments and Services
- Probes and resource management
- Kustomize/Helm
- Rollouts and rollback
- AKS identity/networking

## Phase 4 — DevSecOps

- Entra ID and RBAC
- Key Vault
- OIDC/federated identity
- Secret/dependency scanning
- CODEOWNERS and environment protection

## Phase 5 — Microsoft Fabric operations

- Workspace deployment patterns
- Lakehouse/Warehouse dependencies
- Notebook automation
- Synchronization validation
- Capacity monitoring

## Phase 6 — Evidence

For every project, capture:

- Architecture diagram
- Problem statement
- Implementation
- Pipeline run evidence
- Security controls
- Failure scenario
- Rollback/recovery
- Lessons learned

The evidence is what turns a technology list into a portfolio.
